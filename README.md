# วุ้นแปลภาษาพม่า V19 — คู่มือติดตั้งและอัปเกรด

## เริ่มใช้งานในเครื่อง (ลำดับ)
1. `1_install.bat` — ติดตั้ง Python libraries ลง .venv
2. `0_setup_env.bat` — ตั้งค่า .env แบบถาม-ตอบ: เปิดเว็บที่ต้องใช้ให้ (พิมพ์ o) และทดสอบฐานข้อมูล / Apps Script / Gemini ทันที
3. `4_diagnose.bat` — ตรวจทั้งระบบ + บันทึกตัวอย่างเสียงไว้ฟังเทียบใน logs\samples
4. `2_start.bat` — เปิดโปรแกรม (http://127.0.0.1:8000) · `3_stop.bat` — ปิด

## มีอะไรใหม่ใน V19 — แก้ "แปลภาษาไม่สำเร็จทุกช่องทาง" บน Render
**สาเหตุ:** Render ฟรีใช้ IP ร่วมกับเว็บอื่นจำนวนมาก Google/MyMemory แบบไม่ใช้คีย์จึงตอบ 429 / โควตาหมดเกือบตลอด
และบน Render ยังไม่ได้ตั้งช่องทางที่ผูกบัญชี (Apps Script / Gemini)

**V19 แก้ 2 ชั้น**
1. **แปลผ่านเบราว์เซอร์อัตโนมัติ** — ถ้าเซิร์ฟเวอร์แปลไม่ได้ หน้าเว็บจะให้เบราว์เซอร์ของผู้ใช้แปลเอง (ใช้ IP ของผู้ใช้ ไม่ใช่ IP ของ Render)
   ลำดับ: Google → Google สำรอง → MyMemory แล้วส่งคำแปลให้เซิร์ฟเวอร์สร้างเสียง (ทดสอบจริงจาก Chrome: เรียกได้ ~0.1 วินาที)
   - เซิร์ฟเวอร์ยังใช้คำแปลที่จำไว้/ที่ Admin แก้ก่อนเสมอ และจำคำแปลจากเบราว์เซอร์ไว้ใช้ครั้งต่อไป
   - เมื่อเซิร์ฟเวอร์แปลไม่ได้ จะข้ามไปแปลผ่านเบราว์เซอร์ทันทีเป็นเวลา 10 นาที (ไม่ต้องรอ) แล้วค่อยลองเซิร์ฟเวอร์ใหม่
   - ปุ่ม "แปลให้" ในข้อความสำเร็จรูปใช้วิธีเดียวกัน
2. **ตั้งช่องทางที่ผูกบัญชีบน Render** (Environment): `GAS_URL`, `GAS_SECRET`, `GEMINI_API_KEY`, `MYMEMORY_EMAIL`
   — ไม่ขึ้นกับ IP ของ Render · Admin → สถานะระบบ จะเตือนถ้ายังไม่ได้ตั้ง

## 1. V15 แก้ปัญหา "Server Error: You made too many requests…"

**สาเหตุ:** V14 แปลผ่าน 2 ช่องทางเท่านั้น (Google หน้าเว็บ + MyMemory แบบไม่ระบุตัวตน)
- MyMemory แบบไม่ระบุตัวตนให้แปลได้ **5,000 ตัวอักษร/วัน ต่อ IP** และ Render ฟรีใช้ IP ร่วมกับเว็บอื่นจำนวนมาก โควตาจึงหมดเร็วแล้วตอบกลับ HTTP 429
- ข้อความ Error พูดถึง Google แม้จะเลือก MyMemory เพราะไลบรารี `deep-translator` ใช้ข้อความเดียวกันทุกช่องทาง
- MyMemory รับได้ครั้งละ 500 **byte** (ภาษาไทย 1 ตัว = 3 byte) แต่ V14 ส่งครั้งละ 450 ตัวอักษร และยิงแยกบรรทัดละ 1 ครั้ง

**สิ่งที่ V15 ทำ**
| เรื่อง | รายละเอียด |
|---|---|
| หลายช่องทาง ฟรีทั้งหมด | ถ้าช่องทางหนึ่งเต็ม/ล้ม จะสลับไปช่องทางถัดไปเองอัตโนมัติ (ผู้ใช้ไม่เห็น Error) |
| พักช่องทางที่โดนจำกัด | โดน 429 → พักช่องทางนั้น 1–30 นาที (โควตารายวันหมด → พักตามที่ผู้ให้บริการบอก) จะได้ไม่ยิงซ้ำให้โดนแบนหนักขึ้น |
| จำคำแปลทีละบรรทัด | ข้อความยาวที่มีบางบรรทัดเคยแปลแล้ว จะแปลเฉพาะบรรทัดใหม่ |
| รวมบรรทัดเป็นคำขอเดียว | Google: ข้อความ 3,000 ตัวอักษรใช้คำขอเดียว (V14 ใช้บรรทัดละ 1 ครั้ง) · MyMemory ตัดตาม byte ถูกต้อง |
| ไม่ส่งซ้ำ | กดซ้ำด้วยข้อความ/การตั้งค่าเดิม → เล่นเสียงเดิมโดยไม่เรียกเซิร์ฟเวอร์ |
| หน้าสถานะ | Admin → สถานะระบบ: ดูว่าแต่ละช่องทาง พร้อม/พัก/ล้มเพราะอะไร + ปุ่ม "ทดสอบช่องทางแปลทั้งหมด" |

## 2. ช่องทางแปล (ฟรีทั้งหมด) — ลำดับที่ระบบลองใช้

| ลำดับ | ช่องทาง | ต้องตั้งค่า | โควตาฟรี | หมายเหตุ |
|---|---|---|---|---|
| 1 | **Google Apps Script (ของคุณเอง)** | `GAS_URL`, `GAS_SECRET` | 5,000 ครั้ง/วัน | **แนะนำที่สุด** ใช้ Google Translate ผ่านบัญชีคุณ ไม่โดนจำกัดเพราะ IP ของ Render (ข้อ 4) |
| 2 | Google (`translate.googleapis.com`) | – | ไม่ประกาศ | ใช้ได้ทันที คุณภาพดีที่สุด |
| 3 | Google สำรอง (`clients5.google.com`) | – | ไม่ประกาศ | คนละเซิร์ฟเวอร์กับข้อ 2 |
| 4 | Gemini AI | `GEMINI_API_KEY` | ตาม AI Studio | สมัครฟรีที่ aistudio.google.com (ข้อ 5) |
| 5 | MyMemory | (`MYMEMORY_EMAIL`) | 5,000 → **50,000** ตัว/วัน เมื่อใส่อีเมล | ใส่อีเมลจริงของคุณ |
| 6 | Cloudflare Workers AI (m2m100) | `CF_ACCOUNT_ID`, `CF_API_TOKEN` | 10,000 neurons/วัน | คุณภาพด้อยกว่า ใช้เป็นตัวสำรอง (ข้อ 6) |
| 7 | Google หน้าเว็บ (วิธีเดิม V14) | – | – | ทางสุดท้าย |

ช่องทางที่ยังไม่ได้ตั้งค่าจะถูกข้ามเอง เปลี่ยนลำดับได้ด้วย `TRANSLATE_ORDER` (ค่าเริ่มต้น `gas,google,google2,gemini,mymemory,cloudflare,googleweb`)
ถ้าผู้ใช้เลือกช่องทางเองแล้วช่องทางนั้นล้ม ระบบจะใช้ช่องทางอื่นแทน แล้วแสดงป้าย "(สำรอง — … ใช้ไม่ได้ขณะนี้)"

> ช่องทางฟรีของ Microsoft Edge (`edge.microsoft.com/translate/auth`) ถูกปิดแล้ว (ตอบ 404) จึงไม่ได้ใส่ไว้

## 3. ค่าที่ควรตั้งเพิ่มใน Render → Environment (ขั้นต่ำ 2 นาที)

|-----|-------|

## 4. ตั้งค่า Google Apps Script (ฟรี · ~5 นาที · แนะนำ)
1. เปิด https://script.google.com → **New project**
2. ลบโค้ดเดิม วางโค้ดจากไฟล์ `google_apps_script.gs` ทั้งหมด
3. แก้บรรทัด `const SECRET = '...'` เป็นข้อความสุ่มยาว ๆ แล้วกด Save
4. **Deploy → New deployment** → ไอคอนเฟือง เลือก **Web app**
   - Execute as: **Me** · Who has access: **Anyone** → Deploy → กด Authorize (อนุญาตบัญชีของคุณ)
5. คัดลอก **Web app URL** (ลงท้าย `/exec`) → เปิดในเบราว์เซอร์ ควรเห็น `{"ok":true, ... "sample":"…ภาษาพม่า…"}`
6. Render → Environment: `GAS_URL` = URL นั้น, `GAS_SECRET` = ข้อความเดียวกับข้อ 3 → Save (Render จะ deploy ใหม่)
7. เว็บแอป → Admin → สถานะระบบ → **ทดสอบช่องทางแปลทั้งหมด** — Apps Script ต้องขึ้น ✓

ถ้าแก้โค้ดใน Apps Script ภายหลัง ต้อง Deploy → **Manage deployments → Edit → New version** (URL เดิม)

## 5. Gemini API (ฟรี · ไม่ต้องใช้บัตร)
1. https://aistudio.google.com → **Get API key** → Create API key
2. Render: `GEMINI_API_KEY` = คีย์นั้น
3. (ไม่บังคับ) `GEMINI_MODEL` = ชื่อรุ่น ถ้ารุ่นเริ่มต้นใช้ไม่ได้ — ระบบลองรุ่นตามลำดับ `gemini-3.5-flash-lite, gemini-3.1-flash-lite, gemini-2.5-flash-lite, gemini-2.0-flash`
   โควตาฟรีของแต่ละรุ่นดูได้ใน AI Studio (Google ปรับบ่อย)

## 6. Cloudflare Workers AI (ฟรี)
1. Cloudflare Dashboard → **AI → Workers AI** → ดู **Account ID**
2. **Use REST API → Create a Workers AI API Token**
3. Render: `CF_ACCOUNT_ID`, `CF_API_TOKEN`

## 7. ลด Error ในอนาคต (สรุป)
- ตั้ง `GAS_URL` + `MYMEMORY_EMAIL` อย่างน้อย → มีช่องทางที่ไม่ขึ้นกับ IP ของ Render
- ข้อความที่ประกาศบ่อย ให้ Admin เพิ่มเป็น **ข้อความสำเร็จรูป** พร้อมคำแปล → ไม่ต้องเรียกบริการแปลเลย
- ปิด **Real-Time** เมื่อไม่จำเป็น (โหมดนี้แปลทุกครั้งที่หยุดพิมพ์ 2 วินาที)
- ถ้าหน้า "สถานะระบบ" ขึ้นว่าช่องทางหลักพักบ่อย ให้ตั้งช่องทางที่มีบัญชีของตัวเอง (Apps Script / Gemini) เพิ่ม

## 8. ฐานข้อมูล (เหมือน V14)
ผู้ใช้หายหลัง reboot = เว็บไม่ได้ต่อ Supabase ให้ไล่เช็ก:
1. Render → Settings → Root Directory ชี้โฟลเดอร์ที่มี `main.py` ตัวใหม่
2. Render → Environment ต้องมี `DATABASE_URL` (Supabase **Session pooler**, host ลงท้าย `pooler.supabase.com`)
3. อย่าใช้ Render PostgreSQL ฟรี (ถูกลบหลัง 30 วัน)
4. Supabase ถูก Pause หลังไม่ใช้งาน 7 วัน → ตั้ง UptimeRobot/cron-job.org เรียก `https://<ชื่อเว็บ>.onrender.com/healthz` ทุก 10 นาที

| Key | Value |
|-----|-------|
| `DATABASE_URL` | Supabase connection string (Session pooler) |
| `JWT_SECRET` | ข้อความสุ่มยาว ≥ 32 ตัว |
| `ADMIN_PASSWORD` | (ไม่บังคับ) รหัส admin ตอนฐานข้อมูลว่างครั้งแรก |

Build: `pip install -r requirements.txt` · Start: `uvicorn main:app --host 0.0.0.0 --port $PORT` · Health Check Path: `/healthz`

- Admin → สถานะระบบ: ตารางช่องทางแปล, ปุ่มทดสอบทุกช่องทาง, ปุ่มล้างสถานะพัก
- เสียง Google (พม่า/ไทย) + สลับบริการเสียงอัตโนมัติ + ความเร็วไม่เพี้ยนโทน + ช่วงหยุดระหว่างภาษา · ถอดเสียง Achara ที่ Microsoft เลิกให้บริการ
- **แก้บั๊ก:** Admin กด "รีเซ็ตรหัส" หรือเปลี่ยนสิทธิ์ผู้ใช้ แล้วบัญชีนั้นถูก "ปิดใช้งาน" ไปด้วย (เกิดกับ FastAPI รุ่นใหม่ที่ Render ติดตั้งให้)
