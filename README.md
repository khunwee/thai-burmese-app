# วุ้นแปลภาษาพม่า V14 — คู่มือติดตั้งและอัปเกรด

## 1. สาเหตุที่ "user ใหม่หายหลัง reboot"

ทดสอบโค้ด V13 กับ PostgreSQL จริงแล้ว: สร้าง user → restart → **user ยังอยู่** แปลว่าโค้ด V13 ไม่ใช่ต้นเหตุ
อาการ "admin ยังเข้าได้ แต่ user ที่สร้างใหม่หาย" เกิดได้อย่างเดียวคือ **เว็บที่รันอยู่ไม่ได้เก็บข้อมูลไว้ใน Supabase** แต่สร้างฐานข้อมูลใหม่ทุกครั้งที่เครื่องเริ่มทำงาน (admin ถูกสร้างใหม่ด้วยรหัส 123456 ทุกครั้ง) ให้ไล่เช็กตามนี้:

| # | ตรวจสอบ | วิธีดู |
|---|---------|-------|
| 1 | Render ยัง deploy โค้ดเก่า (SQLite) อยู่ | Render → Settings → **Root Directory** ต้องชี้โฟลเดอร์ที่มี `main.py` ตัวใหม่ · ดู Events ว่า commit ล่าสุดตรงกับที่ push ไป |
| 2 | ไม่ได้ตั้ง `DATABASE_URL` ในบริการที่รันจริง | Render → Environment ต้องมี `DATABASE_URL` (ไม่ใช่แค่ใน render.yaml) |
| 3 | `DATABASE_URL` ชี้ Render PostgreSQL ฟรี | Render Postgres ฟรีถูก **ลบทิ้ง** เมื่อหมดช่วงฟรี (30 วัน) — ต้องใช้ Supabase |
| 4 | Supabase โปรเจกต์ถูก **Pause** (ไม่มีการใช้งาน 7 วัน) | Supabase Dashboard → กด Restore · ป้องกันด้วยข้อ 4 ด้านล่าง |
| 5 | ใช้ Direct connection (`db.xxx.supabase.co`) | เป็น IPv6 — Render ต่อไม่ได้ ให้ใช้ **Session pooler** |

**V14 ช่วยวินิจฉัยให้ทันที:** เมนู *จัดการ (Admin) → สถานะระบบ* แสดงชนิดฐานข้อมูล, host, จำนวนผู้ใช้, เวลาเซิร์ฟเวอร์เริ่มทำงาน และคำเตือน — ถ้าไม่ได้ตั้ง DATABASE_URL หน้าเว็บจะขึ้นแถบแดงเตือน และ **ไม่มีการแอบเก็บข้อมูลลงไฟล์ชั่วคราวอีกต่อไป**

## 2. ตั้งค่า Supabase (Connection string)
1. Supabase → โปรเจกต์ → ปุ่ม **Connect** (ด้านบน) → แท็บ *Connection String*
2. เลือก **Session pooler** (host ลงท้าย `pooler.supabase.com`, port `5432`) — ใช้ Transaction pooler port `6543` ก็ได้
3. แทน `[YOUR-PASSWORD]` ด้วยรหัสผ่าน Database จริง (ไม่ต้องมีวงเล็บ `[ ]`)
   รหัสมีอักขระพิเศษ เช่น `@ # / ?` ได้ — V14 เข้ารหัสให้อัตโนมัติ

## 3. ตั้งค่า Render
Environment Variables:

| Key | Value |
|-----|-------|
| `DATABASE_URL` | connection string จากข้อ 2 |
| `JWT_SECRET` | ข้อความสุ่มยาว ≥ 32 ตัว (ถ้าใช้ render.yaml ระบบสุ่มให้) |
| `ADMIN_PASSWORD` | (ไม่บังคับ) รหัส admin ตอนฐานข้อมูลว่างเปล่าครั้งแรก |

Build: `pip install -r requirements.txt`
Start: `uvicorn main:app --host 0.0.0.0 --port $PORT`
Health Check Path: `/healthz`

## 4. กันเว็บหลับ + กัน Supabase Pause (สำคัญ)
สมัคร **UptimeRobot** หรือ **cron-job.org** (ฟรี) ให้เรียก `https://<ชื่อเว็บ>.onrender.com/healthz` ทุก 10 นาที
- Render ฟรีจะไม่หลับ (ไม่ต้องรอ 30–60 วินาทีตอนเปิดครั้งแรก)
- `/healthz` query ฐานข้อมูลจริง → Supabase ไม่ถูก Pause

## 5. อัปเกรดจาก V13
ใช้ `DATABASE_URL` เดิมได้เลย — V14 เพิ่มคอลัมน์/ตารางให้อัตโนมัติ ข้อมูลเดิมไม่หาย
รหัสผ่านแบบเก่า (SHA256) ยังล็อกอินได้ และถูกอัปเกรดเป็น PBKDF2 อัตโนมัติเมื่อล็อกอิน
admin ที่ยังใช้ 123456 จะถูกบังคับเปลี่ยนรหัสผ่านครั้งแรก

**ทดสอบความถาวร:** สร้าง user → Render → *Manual Deploy* หรือ *Restart* → เปิด *สถานะระบบ* อีกครั้ง: "เซิร์ฟเวอร์เริ่มทำงาน" ต้องเป็นเวลาใหม่ และ "จำนวนผู้ใช้" ต้องเท่าเดิม

## 6. รันบนเครื่องตัวเอง
```
pip install -r requirements.txt
copy .env.example .env      (แก้ DATABASE_URL ใน .env)
uvicorn main:app --reload
```
ห้ามอัปโหลด `.env` ขึ้น GitHub (มี `.gitignore` กันไว้แล้ว)

## 7. สิ่งที่เปลี่ยนใน V14
**แก้ปัญหา/ความปลอดภัย**
- ลบ `/shutdown` (เดิมใครก็ปิดเซิร์ฟเวอร์ได้โดยไม่ต้องล็อกอิน)
- เลิกใช้ JWT secret ค่าตายตัว (เดิมปลอม token เป็น admin ได้) — สุ่มแล้วเก็บในฐานข้อมูล, token ไม่หลุดเมื่อ restart
- รหัสผ่าน PBKDF2 + salt, ล็อกชั่วคราวเมื่อใส่ผิด 5 ครั้ง
- ลบ/ปิด/รีเซ็ตรหัส user แล้ว session เดิมใช้ไม่ได้ทันที; เปลี่ยนสิทธิ์มีผลทันที
- กันลบตัวเอง / กันลบ admin คนสุดท้าย
- แก้ XSS ในตารางรายชื่อผู้ใช้
- ไฟล์เสียงแยกต่อคำขอ (เดิมทุกคนใช้ `output.mp3` ไฟล์เดียว เสียงสลับกันได้)
- ดาวน์โหลด WAV/OGG แปลงตอนกด (เดิมเปลี่ยนฟอร์แมตแล้ว "File not found" หรือได้เสียงของคนอื่น)
- ต่อฐานข้อมูลใหม่อัตโนมัติเมื่อ connection หลุด, connection pool, SSL, timeout
- ตรวจค่าที่ส่งเข้ามาทั้งหมด (เสียง/ความเร็ว/ฟอร์แมต/ความยาวข้อความ)
- แปลข้อความยาวได้ (ตัดเป็นช่วงอัตโนมัติ — MyMemory รับได้ครั้งละ ~500 ตัว)
- รองรับ Render cold start: แจ้งสถานะ + ลองใหม่อัตโนมัติ

**ฟีเจอร์ใหม่**
- ข้อความสำเร็จรูป (แยกหมวด) — คลิกใส่ข้อความ, ดับเบิลคลิกประกาศทันที
- แก้คำแปลพม่าแล้วพูดใหม่ได้; Admin บันทึกเป็น "คำแปลถาวร"
- จำคำแปล (cache) — ข้อความเดิมไม่ต้องแปลซ้ำ เร็วขึ้นและคำแปลคงที่; ปุ่ม "แปลใหม่"
- ประกาศสองภาษา: ไทย→พม่า หรือ พม่า→ไทย พร้อมเลือกเสียงไทย
- เล่นซ้ำ 1–5 รอบ, Ctrl+Enter, คัดลอกคำแปล
- ประวัติการประกาศ (เล่นซ้ำได้; Admin ดูของทุกคน)
- จัดการผู้ใช้: ชื่อที่แสดง, เปลี่ยนสิทธิ์, เปิด/ปิดบัญชี, รีเซ็ตรหัส, เวลาเข้าใช้ล่าสุด
- ทุกคนเปลี่ยนรหัสผ่านของตัวเองได้
- หน้าสถานะระบบ + `/healthz`
- ฟอนต์พม่า Noto Sans Myanmar (แสดงผลถูกต้องบน Windows ที่ไม่มีฟอนต์พม่า)
- จำตัวเลือกเสียงของแต่ละคนไว้ในเบราว์เซอร์
